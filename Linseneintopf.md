## Zutaten (5 Portionen)

| Menge       | Zutat                   |
| ----------- | ----------------------- |
| 1           | Zwiebel                 |
| 250 g       | Linsen (grün)           |
| 300 g       | festkochende Kartoffeln |
| 200 g       | Karotten                |
| 1,5 L       | Wasser                  |
| 6 TL / 2 EL | Gemüsebrühe-Pulver      |
| 1 TL        | Knoblauchpulver         |
| 1 TL        | Paprikapulver           |
| 1 TL        | Tomatenmark             |
|             | Salz                    |
|             | Pfeffer                 |

## Zubereitung 

1. Zwiebel mit bisschen Öl im Topf anbraten
2. Kartoffeln und Karotten in kleine Würfel schneiden
3. Alles zusammen in den Topf geben
4. 25–30 Minuten köcheln lassen
