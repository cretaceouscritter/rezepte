## Zutaten (4 Portionen)

| Menge | Zutat                     |
| ----- | ------------------------- |
| 160 g | Linsen (rot)              |
| 100 g | mehligkochende Kartoffeln |
| 100 g | Karotten                  |
| 1 L   | Wasser                    |
| 20g   | Tomatenmark               |
| 1     | Zwiebel                   |
| 1 TL  | Paprika edelsüß           |
| 1 TL  | Kurkuma                   |
| 1 TL  | schwarzer Pfeffer         |
## Zubereitung

1. Zwiebel mit bisschen Öl im Topf anbraten
2. Kartoffeln und Karotten in kleine Würfel schneiden
3. Alles zusammen in den Topf geben
4. 25–30 Minuten köcheln lassen
5. Würzen
6. Einmal im Topf Pürieren
